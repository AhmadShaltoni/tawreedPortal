### الشاشة 3: اختيار متقدم

```
الحالة 1: المستخدم يختار
  ┌─────────────────┐
  │ حجم: 1 لتر     │
  │ نكهة: بدون سكر  │
  │ وحدة: دزينة    │
  │ كمية: 2        │
  └─────────────────┘
            ↓
         السعر:
    - سعر الدزينة الأساسي: 28.0 JOD
    - لكن هناك override للنكهة: 3.0 JOD
    - 3.0 JOD × 12 قطعة = 36.0 JOD للدزينة
    - 36.0 JOD × 2 دزينة = 72.0 JOD
            ↓
       [ إضافة للسلة ]
            ↓
  POST /api/v1/cart
  {
    variantId: "var-1l",
    optionId: "opt-sugar-free",
    unitId: "unit-dozen",
    quantity: 2
  }
```

## 🔄 دورة الحياة (Lifecycle)

```
1. المستخدم يفتح التطبيق
   ↓
2. GET /api/v1/products (قائمة القطع)
   ↓
3. عرض المنتجات بـ default variant + unit
   ↓
4. المستخدم ينقر على منتج
   ↓
5. GET /api/v1/products/[id] (كامل التفاصيل)
   ↓
6. عرض صفحة تفاصيل مع جميع الخيارات
   ↓
7. المستخدم يختار:
   - الحجم (variant)
   - النكهة (option)
   - الوحدة (unit)
   - الكمية (quantity)
   ↓
8. حساب السعر النهائي
   ↓
9. المستخدم ينقر "إضافة للسلة"
   ↓
10. POST /api/v1/cart
    ↓
11. عرض رسالة نجاح
    ↓
12. المستخدم يتابع التسوق أو يذهب للسلة
```

## 💰 حساب السعر

```
┌─────────────────────────────────────┐
│   كيف يتم حساب السعر النهائي؟      │
└─────────────────────────────────────┘

خطوة 1: ابدأ بسعر الوحدة
  price = unit.price  (مثلاً: 28.0 JOD)

خطوة 2: تحقق من النكهة
  IF option.priceOverride != null THEN
    price = option.priceOverride  (مثلاً: 3.0 JOD)
    THEN لكل وحدة لها عدة قطع:
      price = option.priceOverride × unit.piecesPerUnit
      (3.0 × 12 = 36.0 JOD للدزينة)

خطوة 3: اضرب بـ الكمية
  totalPrice = price × quantity
  (36.0 × 2 = 72.0 JOD)

مثال حقيقي:
  ─────────────────────────────────
  unit.price = 28.0 JOD (دزينة)
  option.priceOverride = 3.0 JOD (بدون سكر)
  quantity = 2 دزينة
  
  price = 3.0 × 12 = 36.0 JOD
  totalPrice = 36.0 × 2 = 72.0 JOD
  ─────────────────────────────────
```

## 📊 جدول المخزون

```
Variant: 1 لتر
├─ Option: طبيعي        (stock: 50)
├─ Option: بدون سكر     (stock: 30)
└─ Option: فيتامين C    (stock: 20)
   ─────────────────────
   إجمالي المخزون: 100

الخلاصة:
- variant.stock = 100
- option[0].stock = 50  ← ابدأ من هنا عند الاختيار
- option[1].stock = 30
- option[2].stock = 20
```

## 🔌 API Endpoints Flow

```
┌─ قائمة المنتجات
│  GET /api/v1/products?page=1&limit=20
│  ↓ رد سريع (view=card)
│  {products: [{id, name, image, defaultPrice}]}
│
├─ تفاصيل منتج
│  GET /api/v1/products/[id]
│  ↓ رد كامل
│  {product: {variants: [{units: [], options: []}]}}
│
├─ بحث
│  GET /api/v1/search?q=عصير
│  ↓ نتائج البحث
│  {products: [...]}
│
├─ حسب الفئة
│  GET /api/v1/products?categoryId=[id]
│  ↓ منتجات الفئة
│  {products: [...]}
│
├─ حسب الماركة
│  GET /api/v1/brands/[slug]/products
│  ↓ منتجات الماركة
│  {brand: {...}, products: [...]}
│
├─ السلة
│  POST /api/v1/cart
│  ← {variantId, optionId, unitId, quantity}
│  ↓ تم الإضافة
│  {success: true}
│
└─ الشراء
   POST /api/v1/orders
   ← {items: [...], deliveryAddress, ...}
   ↓ تم الطلب
   {order: {id, ...}}
```

## 🎯 خريطة الاستخدامات

```
منتج بدون خيارات
├─ 1 حجم واحد
├─ 1 وحدة بيع (أو أكثر)
└─ بدون نكهات
   مثال: أرز أبيض 5 كيلو

منتج بنكهات
├─ 1 حجم واحد
├─ 1 وحدة بيع (أو أكثر)
└─ عدة نكهات (مثل: تفاح، برتقال)
   مثال: عصير برتقال 1 لتر

منتج بأحجام متعددة
├─ عدة أحجام (مثل: 1 لتر، 2 لتر)
├─ كل حجم له وحداته
└─ كل حجم قد يكون له نكهات
   مثال: عصير برتقال (1 لتر، 2 لتر)

منتج معقد
├─ عدة أحجام
├─ كل حجم له عدة وحدات
├─ كل حجم له عدة نكهات
└─ قد تكون هناك أسعار مختلفة لكل نكهة
   مثال: عصير برتقال الفاخر
```

### استخدم `view=card` للقائمة

```

GET /api/v1/products?page=1  (كامل التفاصيل)

GET /api/v1/products?page=1&view=card
Payload: ~50 KB (بيانات خفيفة فقط)
```
