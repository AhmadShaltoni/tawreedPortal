## 📱 Endpoints المدعومة

### 1. POST `/api/v1/orders` - إنشاء الطلب
```json
✅ الموبايل يرسل: deliveryAddress, deliveryCity, buyerNotes
✅ الـ Cart Items تحتوي على: variantOptionName, variantSize, unitLabel
✅ يتم حفظ كل البيانات بنجاح
```

### 2. GET `/api/v1/orders` - قائمة الطلبات (للموبايل)
```json
✅ يرجع جميع الطلبات مع التفاصيل الكاملة
✅ تم اختبار: حفظ البيانات بشكل صحيح
```

### 3. GET `/api/v1/orders/[id]` - تفاصيل طلب واحد (للموبايل)
```json
✅ يرجع البيانات الكاملة مع selectedFlavor
✅ مثال:
{
  "selectedFlavor": {
    "name": "تفاح أحمر",
    "nameEn": "Red Apple"
  }
}
```

### 4. Server Action `getAdminOrderById()` - جلب للداشبورد
```typescript
✅ يجلب جميع البيانات من قاعدة البيانات
✅ يشمل: variantOptionName, variantOptionNameEn
✅ تم تحديث Props Type لاستقبالها
```
