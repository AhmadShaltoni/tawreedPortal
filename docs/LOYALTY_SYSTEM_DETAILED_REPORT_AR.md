## نظرة عامة

### ما هو نظام الولاء؟

**نظام الولاء والمكافآت** هو برنامج متكامل لمكافأة العملاء (المشترين) على تعاملهم مع المنصة. يتضمن:

- ✅ **كسب النقاط**: العملاء يحصلون على نقاط من عمليات الشراء
- ✅ **المكافآت**: تحويل النقاط إلى مكافآت (خصومات، توصيل مجاني، إلخ)
- ✅ **برنامج الإحالة**: كسب نقاط بإحالة عملاء جدد
- ✅ **الحملات**: تحديات لكسب نقاط إضافية (مثل: اشتر ب 500 دينار)
- ✅ **الكوبونات**: استخدام النقاط للحصول على كوبونات خصم

### المزايا للعملاء

| الميزة | الفائدة |
|--------|--------|
| **الكسب من كل عملية شراء** | 10 نقاط لكل 1 دينار (قابل للتعديل) |
| **مكافأة الترحيب** | 100 نقطة عند التسجيل أو أول طلب (قابل للتعديل) |
| **برنامج الإحالة** | 50 نقطة لك و50 نقطة للشخص المُحال (قابل للتعديل) |
| **حملات إضافية** | تحديات مثل "اشتر ب 500 دينار واحصل على 200 نقطة" |
| **تحويل إلى خصومات** | مثلاً: 500 نقطة = خصم 10 دنانير |

## كيفية عمل النقاط

### 1️⃣ متى يتم كسب النقاط؟

#### أ) من الطلبات (EARN_ORDER)
```
✅ الشرط: عندما يتغير حالة الطلب إلى "DELIVERED" (تم التسليم)
✅ الحساب: (سعر الطلب - رسم التوصيل) × (نقاط/دينار)
✅ مثال:
   - سعر الطلب: 100 دينار
   - رسم التوصيل: 5 دنانير
   - المبلغ الأساسي: 100 - 5 = 95 دينار
   - النقاط: 95 × 10 = 950 نقطة
```

#### ب) مكافأة الترحيب (EARN_WELCOME)
```
✅ متى: عند التسجيل أو أول طلب مُسلَّم
✅ القيمة: 100 نقطة (قابل للتعديل)
✅ مرة واحدة فقط لكل عميل
```

#### ج) برنامج الإحالة (EARN_REFERRAL)
```
✅ للمُحيل (الشخص الأصلي): 50 نقطة
✅ للمُحال (العميل الجديد): 50 نقطة
✅ متى: عندما يضع المُحال أول طلب مُسلَّم
✅ مرة واحدة فقط لكل إحالة
```

#### د) من الحملات (EARN_CAMPAIGN)
```
✅ متى: عندما يصل العميل إلى هدف الحملة
✅ أنواع الأهداف:
   - SPEND_AMOUNT: إنفاق مبلغ معين (مثلاً 500 دينار)
   - ORDER_COUNT: عدد الطلبات (مثلاً 5 طلبات)
✅ المكافأة: نقاط معينة تُحدد من الإدارة (مثلاً 200 نقطة)
```

### 2️⃣ متى يتم صرف النقاط؟

```
❌ الطريقة: استخدام النقاط مباشرة في الطلب؟
   ❌ لا! هذه ليست كيفية العمل

✅ الطريقة الصحيحة: تحويل النقاط إلى كوبونات خصم
   1. العميل يختار "مكافأة" (مثلاً: خصم 10 دنانير)
   2. تكلفة المكافأة: 500 نقطة
   3. إذا كان لديه 500 نقطة أو أكثر، يمكنه استرجاع المكافأة
   4. يحصل على كوبون فريد (مثل: LOYALTY-1716027000-A3F9K2)
   5. يستخدم الكوبون عند الدفع
```

### 3️⃣ آلية الحساب التفصيلية

```typescript
// صيغة الحساب
نقاط = (سعر_الطلب - رسم_التوصيل) / قاعدة_الحساب × نقاط_لكل_دينار

// إعدادات قابلة للتعديل
- نقاط_لكل_دينار: 10 (مثلاً 10 نقاط لكل دينار)
- قاعدة_الحساب: 1 (دينار واحد)
- استبعاد_رسم_التوصيل: نعم (رسم التوصيل لا يُحتسب)
- طريقة_التقريب: FLOOR (تقريب لأسفل)

// مثال:
إذا: سعر الطلب = 75.50 دينار، رسم التوصيل = 5 دنانير
المبلغ الأساسي = 75.50 - 5 = 70.50 دينار
النقاط = 70.50 × 10 = 705 نقاط
```

### 4️⃣ الحماية من التكرار

```
⚠️ المشكلة: ماذا لو تم حساب النقاط مرتين لنفس الطلب؟

✅ الحل: النظام يفحص حقل "loyaltyPointsEarned" في الطلب
   - إذا كان الحقل null/undefined → حساب النقاط
   - إذا كان الحقل يحتوي على قيمة → لا تحسب مرة أخرى
```

#### Endpoint
```
GET /api/v1/loyalty/balance
```

#### المصادقة
```

```

#### الاستجابة (نجاح)
```json

  "balance": {
    "userId": "user-123",
    "totalEarned": 1500,      // إجمالي النقاط المكسوبة
    "totalRedeemed": 300,     // إجمالي النقاط المستخدمة
    "currentBalance": 1200    // الرصيد الحالي (المتبقي)
  },
  "recentTransactions": [
    {
      "id": "txn-456",
      "type": "EARN_ORDER",
      "points": 150,
      "description": "نقاط من الطلب #12345",
      "descriptionEn": "Points from order #12345",
      "createdAt": "2026-05-18T10:30:00Z",
      "metadata": { "orderId": "order-123" }
    },
    {
      "id": "txn-789",
      "type": "EARN_WELCOME",
      "points": 100,
      "description": "مكافأة الترحيب",
      "descriptionEn": "Welcome bonus",
      "createdAt": "2026-05-15T14:20:00Z"
```

#### ماذا يعني؟
- **totalEarned**: كل النقاط التي كسبها هذا العميل من البداية
- **totalRedeemed**: كل النقاط التي حولها إلى كوبونات واستخدمها
- **currentBalance**: النقاط المتبقية = totalEarned - totalRedeemed
- **recentTransactions**: آخر 10 عمليات (تحويل نقاط، كسب نقاط)

#### Endpoint
```

```

#### المعاملات (Parameters)
```
page: رقم الصفحة (اختياري، افتراضي 1)
limit: عدد العمليات في الصفحة (اختياري، افتراضي 20، أقصى 100)
```

#### الاستجابة
```json
{
  "transactions": [
    {
      "id": "txn-1",
      "type": "EARN_ORDER",           // نوع العملية
      "points": 250,
      "description": "نقاط من الطلب #5001",
      "createdAt": "2026-05-20T09:00:00Z",
      "metadata": { "orderId": "order-xyz" }
    },
    {
      "id": "txn-2",
      "type": "REDEEM",              // استخدام نقاط
      "points": -500,                // سالب = استخدام
      "description": "استرجاع مكافأة: خصم 10 دنانير",
      "createdAt": "2026-05-19T15:30:00Z"
    },
    {
      "id": "txn-3",
      "type": "EARN_REFERRAL_INVITER",
      "points": 50,
      "description": "مكافأة إحالة - تم إحالة أحمد محمود",
      "createdAt": "2026-05-18T12:00:00Z"

  "pagination": {
    "page": 1,
    "limit": 20,
    "total": 120,
    "totalPages": 6
  }

```

#### أنواع العمليات (Transaction Types)
```
- EARN_ORDER: كسب من طلب مُسلَّم
- EARN_WELCOME: مكافأة الترحيب
- EARN_REFERRAL_INVITER: إحالة (أنت المُحيل)
- EARN_REFERRAL_INVITEE: إحالة (أنت المُحال)
- EARN_CAMPAIGN: من حملة
- REDEEM: استخدام نقاط لكوبون (سالب)
- MANUAL_ADD: إضافة يدوية من الإدارة
- MANUAL_REMOVE: إزالة يدوية من الإدارة (سالب)
- EXPIRED: نقاط منتهية الصلاحية (سالب)
```

### 4️⃣ استرجاع مكافأة (تحويل نقاط إلى كوبون)

#### Endpoint
```
POST /api/v1/loyalty/rewards/redeem
```

#### البيانات المطلوبة
```json
{
  "rewardId": "reward-1"
}
```

#### الاستجابة (نجاح)
```json
{
  "success": true,
  "couponCode": "LOYALTY-1716027000-A3F9K2"
}
```

#### الاستجابة (خطأ)
```json
{
  "error": "رصيد نقاط غير كافي"
}
```

#### الأخطاء الممكنة
```
- "المكافأة غير متاحة" → المكافأة معطّلة أو محذوفة
- "رصيد نقاط غير كافي" → ليس لديك نقاط كافية
- "لقد وصلت إلى الحد الأقصى لاسترداد هذه المكافأة" → استخدمت المكافأة أكثر من المسموح
```

#### العملية
```
1. يتحقق النظام: هل المكافأة نشطة؟
2. يتحقق: هل لديك نقاط كافية؟
3. يتحقق: هل وصلت إلى حد الاستخدام الأقصى؟
4. إذا موافق: ينقص النقاط من رصيدك
5. ينشئ كوبون فريد
6. ينبهك عبر Push Notification
7. يسجل العملية
```

### 6️⃣ التحقق من الكوبون عند الدفع (الأهم للمتجر)

#### Endpoint
```
POST /api/v1/loyalty/coupons/validate
```

#### البيانات المطلوبة
```json
{
  "couponCode": "LOYALTY-1716027000-A3F9K2",
  "orderTotal": 75.50
}
```

#### الاستجابة (نجاح)
```json
{
  "valid": true,
  "discountAmount": 10,
  "finalTotal": 65.50,
  "couponId": "coupon-1"
}
```

**ماذا يعني؟**
- `valid`: الكوبون صحيح وجاهز للاستخدام
- `discountAmount`: مبلغ الخصم (10 دنانير)
- `finalTotal`: السعر النهائي = 75.50 - 10 = 65.50 دينار
- `couponId`: معرّف الكوبون (تحفظه لتطبيق الخصم)

#### الاستجابة (خطأ)
```json
{
  "error": "انتهت صلاحية هذا الكوبون"
}
```

#### الأخطاء الممكنة
```
- "رمز الكوبون غير صحيح" → الكوبون غير موجود
- "هذا الكوبون لا ينتمي إليك" → الكوبون لشخص آخر
- "تم استخدام هذا الكوبون بالفعل" → الكوبون مستخدم
- "انتهت صلاحية هذا الكوبون" → انتهت مدة صلاحيته
- "الحد الأدنى لمبلغ الطلب هو X JOD" → طلبك أقل من الحد الأدنى
```

#### طريقة العمل في التطبيق
```
1. العميل يختار كوبون من قائمة كوبوناته
2. يرسل: couponCode + مبلغ الطلب
3. الـ API يتحقق:
   ✓ هل الكوبون صحيح؟
   ✓ هل انتهت صلاحيته؟
   ✓ هل تم استخدامه؟
   ✓ هل مبلغ الطلب يفي بالحد الأدنى؟
4. إذا صحيح: يرجع discountAmount و finalTotal
5. التطبيق يعرض الخصم للعميل
6. عند تأكيد الطلب: يرسل couponId مع بيانات الطلب
7. النظام يطبق الخصم ويلغي الكوبون
```

#### حالة خاصة: توصيل مجاني (FREE_DELIVERY)
```json
{
  "valid": true,
  "discountAmount": 0,              // لا يوجد خصم مباشر
  "finalTotal": 75.50,              // نفس السعر
  "discountType": "FREE_DELIVERY",
  "couponId": "coupon-3"
}
```

**التطبيق يجب أن يتعامل مع هذا:**
- في حالة FREE_DELIVERY: اخفِ رسم التوصيل من الفاتورة
- لا تطرح 0 من السعر

## حساب النقاط

### 📊 مثال عملي شامل

#### المستخدم الأول: أحمد محمود

```
التاريخ      │ العملية                    │ النقاط  │ الرصيد الجديد
─────────────┼────────────────────────────┼─────────┼──────────────
1-1-2026     │ التسجيل                    │ +100    │ 100 (مكافأة الترحيب)
─────────────┼────────────────────────────┼─────────┼──────────────
5-1-2026     │ طلب #1000 مُسلَّم          │ +145    │ 245
             │ (السعر: 95 دينار)          │         │
             │ (95 × 10 = 950 ÷ 10)      │         │
─────────────┼────────────────────────────┼─────────┼──────────────
8-1-2026     │ استرجاع مكافأة: خصم 10 د   │ -500    │ -255
             │ (استخدم 500 نقطة)         │         │
             │ حصل على كوبون             │         │
─────────────┼────────────────────────────┼─────────┼──────────────
10-1-2026    │ إحالة: سارة أحمد (أول طلب)│ +50     │ -205 → 295
             │ (أحمد المُحيل)             │         │
─────────────┼────────────────────────────┼─────────┼──────────────
```

#### تفصيل العملية الأولى
```
1. أحمد يسجل حسابه
   → لوقته: الرصيد = 0
   
2. النظام يتحقق: هل مفعل مكافأة الترحيب؟
   → نعم: 100 نقطة
   
3. يتحقق: متى تُمنح؟ (عند التسجيل أو أول طلب؟)
   → عند التسجيل
   
4. أحمد يحصل على 100 نقطة مباشرة
   → رصيده الجديد: 100 نقطة
```

#### تفصيل عملية الطلب الأول
```
1. أحمد يضع طلب بقيمة: 100 دينار
   - المنتجات: 95 دينار
   - رسم التوصيل: 5 دنانير
   
2. الطلب يُسلَّم (الحالة = DELIVERED)
   
3. النظام يحسب النقاط:
   المبلغ الأساسي = 100 - 5 = 95 دينار
   النقاط = 95 × 10 = 950 ÷ 10 = 95... 
   
   ❌ انتظر! هذا غير صحيح
   
   الصيغة الصحيحة:
   النقاط = (المبلغ الأساسي / قاعدة_الحساب) × نقاط_لكل_دينار
   النقاط = (95 / 1) × 10 = 950
   
   ⏰ لا! هذا أيضاً غير صحيح
   
   الصيغة الصحيحة (كما هي في الكود):
   النقاط = (95 × 10) / 1 = 950
   
   ❓ 950 نقطة؟! هذا كثير
   
   أعادة قراءة الكود...
   النقاط = (baseAmount × pointsPerJod) / calculationBase
   النقاط = (95 × 10) / 1 = 950
   
   ✅ نعم، 950 نقطة صحيحة!
   (يعني عن كل دينار ينفق، يحصل على 10 نقاط)
```

#### تصحيح المثال
```
طلب بـ: 100 دينار
- المنتجات: 95 دينار
- رسم التوصيل: 5 دنانير
النقاط المكسوبة: 95 × 10 = 950 نقطة

في الواقع: هذا كثير جداً!
مثال أكثر واقعية:
```

#### مثال واقعي
```
إعدادات النقاط:
- نقاط لكل دينار: 10
- استبعاد رسم التوصيل: نعم

طلب بـ: 50 دينار
- المنتجات: 45 دينار
- رسم التوصيل: 5 دنانير

الحساب:
المبلغ الأساسي = 45 - 0 = 45 دينار (لأننا نستبعد الرسم)
النقاط = 45 × 10 = 450 نقطة

✅ أحمد يحصل على 450 نقطة من هذا الطلب
```
